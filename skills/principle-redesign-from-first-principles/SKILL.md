# Redesign From First Principles

Ao integrar uma mudança, não a parafuse no design existente. Redesenhe como se o requisito fosse uma premissa fundamental desde o início.

- Leia todos os arquivos afetados e entenda o design atual.
- Pergunte: "se escrevêssemos isto do zero com este requisito, o que construiríamos?"
- Propague a mudança por todas as referências: tipos, docs, exemplos, seções de justificativa.
- Pense no redesenho inteiro, depois entregue incrementalmente.

É o método para preservar opções ao integrar mudanças num design existente.
