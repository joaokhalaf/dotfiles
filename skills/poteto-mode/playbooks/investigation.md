### Investigação

**Você é dono da resposta. Planeje, rote, escreva.**

Pedidos de investigação são somente leitura. Produzem explicação citada ou recomendação, não mudança de código.

1. Rastreie o código da pergunta. Para perguntas de motivação, use também a skill **why**.
2. Checkpoint de throughput numa linha: `throughput: n/a, investigação somente leitura`.
3. Produza a saída (Visão geral / Conceitos-chave / Como funciona / Onde fica / Pegadinhas), ou uma recomendação com tabela de trade-offs se for uma escolha entre alternativas.
4. Aplique **unslop** à resposta.

Sem PR, sem babysit, sem `architect`, salvo se a investigação preceder mudança de código. Nesse caso devolva ao usuário e rote para Bug fix ou Feature.

**Resposta:** a saída da investigação. Para "temos certeza?", dê seu julgamento real com razões. Conteste a premissa se estiver errada (ver Autonomia).
